# World Happiness Report 2015 Data Analysis

## Project Overview
This project investigates the underlying drivers of national happiness by analyzing data from the 2015 World Happiness Report. By examining 158 countries, this analysis explores the complex relationships between economic strength, social support, health metrics, and overall happiness scores to determine which factors have the most significant impact on a nation's well-being.

## Tools & Technologies
* **Analytical Software:** SAS Studio
* **Techniques Used:** Data Cleaning, Exploratory Data Analysis (EDA), Statistical Modeling, Hypothesis Testing

## Methodology
The project follows a rigorous statistical workflow to ensure accurate and interpretable results:
1. **Data Preparation & Visualization:** Cleaning the raw dataset and plotting distributions and scatter plots to identify initial trends and outliers.
2. **Descriptive Statistics:** Summarizing the central tendencies and dispersions of happiness scores and key socio-economic indicators across different regions.
3. **Bivariate Analysis:** 
   * **Pearson Correlation:** Measuring the linear correlation between continuous variables (e.g., GDP per capita, life expectancy) and happiness scores.
   * **Independent-Samples T-Tests:** Comparing average happiness scores across different categorical groups or regions.
4. **Predictive Modeling:** 
   * **Multiple Linear Regression:** Building a regression model to predict happiness scores based on a combination of economic, social, and health factors.
   * **Diagnostic Testing:** Validating model assumptions (linearity, homoscedasticity, independence, and normality of residuals) to ensure the statistical reliability of the model.
